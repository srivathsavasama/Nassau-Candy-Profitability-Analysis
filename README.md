# Nassau Candy Distributor — Product Profitability Analysis

## Project Overview
This project analyzes product profitability and gross profit margins for Nassau Candy Distributor using Python, data analysis, visualization, and machine learning.

## Objectives
- Analyze sales, cost, and gross profit.
- Identify top-performing products.
- Study monthly sales and gross profit trends.
- Compare profitability across regions and shipping modes.
- Explore low-margin products and customer profitability.
- Build an initial machine learning model to estimate gross profit.
- Present key results using a Streamlit dashboard.

## Technologies Used
- Python
- Google Colab and Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Joblib

## Project Files
- `app.py` — Streamlit dashboard.
- `requirements.txt` — Python dependencies.
- `Nassau_Candy_Analysis.ipynb` — analysis notebook (use the actual uploaded filename).

## Dashboard
The dashboard displays key performance indicators, monthly sales and gross profit trends, and the top 10 products by gross profit.

## Dataset
The project uses a Nassau Candy Distributor CSV dataset containing order, product, sales, cost, and gross profit information. The raw dataset is not included in this public repository.

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Make the required dataset available locally, with permission to use it.
5. Run the dashboard:

   `streamlit run app.py`

## Note
The machine learning model and its evaluation should be validated before using predictions for business decisions.
